Does Open-DQI discriminate columns? No! Open-DQI is column-agnostic. It does not require specific column headers:

1. Completeness (25%) Evaluates 100% of all columns in your dataset. Flags empty strings, null, NaN, None, and placeholder characters (-, n/a).
2. Validity (35%) Auto-detects semantic patterns: emails (@), international phones (+234, +254), GPS bounds, dates, and flags non-numeric values in numeric columns.
3. Uniqueness (25%) If an ID column exists (id, nin, code), it checks for key collisions. If not, it compares the full row tuple to detect identical duplicates.
4. Outliers (15%) Applies Tukey IQR fences ($Q_1 - 1.5\text{IQR}, Q_3 + 1.5\text{IQR}$) across all detected numeric fields (e.g. income, farm size, age, revenue).
